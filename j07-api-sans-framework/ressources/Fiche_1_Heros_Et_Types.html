Exercice 1 : les héros et leurs types

Le contexte : un jeu de rôle garde ses héros en mémoire. L'écran du jeu veut afficher leur liste. Il ne lance pas votre programme, il lui envoie des requêtes, et il attend du JSON en réponse.

Ce qui est travaillé : écrire un contrôleur qui va chercher des données, les renvoyer en JSON avec Jackson, et refaire le même geste sur une seconde route.

Question 0, avec la formatrice

Dans votre projet, copiez le modèle dans le paquet rpg.model, et le repository dans le paquet rpg.repository. Relancez : /health répond toujours.

  • Le modèle, ce sont les classes que l'on va utiliser : comme en POO les jours précédents, les moules de nos objets.
  • Le repository fait office de base de données : on y stocke nos objets, et ce sont ses méthodes qui nous les retournent.
package rpg.model;

public class Hero {
    private final String name;
    private final String role; // warrior, mage, archer ou priest
    private final int level;

    public Hero(String name, String role, int level) {
        this.name = name;
        this.role = role;
        this.level = level;
    }

    public String getName() { return name; }
    public String getRole() { return role; }
    public int getLevel() { return level; }
}
package rpg.repository;

import rpg.model.Hero;

import java.util.ArrayList;
import java.util.List;

// Les héros, gardés en mémoire : ils repartent de zéro à chaque redémarrage.
public class HeroRepository {
    private final List<Hero> heroes = new ArrayList<>();

    public HeroRepository() {
        heroes.add(new Hero("Conan", "warrior", 12));
        heroes.add(new Hero("Merlin", "mage", 18));
        heroes.add(new Hero("Robin", "archer", 7));
        heroes.add(new Hero("Frère Tuck", "priest", 5));
        heroes.add(new Hero("Morgane", "mage", 9));
        heroes.add(new Hero("Lancelot", "warrior", 15));
    }

    public List<Hero> findAll() {
        return heroes;
    }
}

La consigne

  1. Le contrôleur : créez HeroController, sur le modèle de votre HealthController. Il a comme attribut HeroRepository, et il répond Json.send(exchange, 200, repository.findAll()).
  2. Main : ajoutez votre nouvelle route /heroes, et testez. GET /heroes renvoie les six héros : [{"name":"Conan","role":"warrior","level":12},{"name":"Merlin",...}].

Astuce : si les champs s'affichent dans l'ordre alphabétique, regardez votre pom.xml. Dans <properties>, sous la ligne de la version Java, ajoutez <maven.compiler.parameters>true</maven.compiler.parameters>, puis rechargez Maven. L'ordre sera désormais celui des attributs dans votre classe.

Partie optionnelle : la description de chaque type

On veut pouvoir afficher un descriptif pour chaque type de héros.

  1. Le modèle : dans rpg.model, créez une classe Role, avec pour attributs le nom du rôle et sa description.
  2. Le repository : créez un RoleRepository, qui donne une description pour chaque rôle : warrior, mage, archer et priest.
  3. Le contrôleur et Main : en reprenant les consignes précédentes, ajoutez la route /roles.
