Exercice 1 : FizzBuzz, puis la règle Qix

La règle. fizzBuzz(n) renvoie « Fizz » si n est divisible par 3, « Buzz » s'il est divisible par 5, « FizzBuzz » s'il est divisible par 3 et par 5, sinon le nombre lui-même.

Question 0, avec la formatrice

Copiez FizzBuzz.java dans src/main/java et FizzBuzzTest.java dans src/test/java. Lancez FizzBuzzTest : le test est vert. Dites-le dans le chat.

public class FizzBuzz {

    public static String fizzBuzz(int n) {
        if (n % 15 == 0) {
            return "FizzBuzz";
        }
        if (n % 3 == 0) {
            return "Fizz";
        }
        if (n % 5 == 0) {
            return "Buzz";
        }
        return String.valueOf(n);
    }
}
import org.junit.jupiter.api.Test;

import static org.junit.jupiter.api.Assertions.assertEquals;

class FizzBuzzTest {

    @Test
    void fizzBuzz_1_returnsNumber() {
        // GIVEN
        int number = 1;
        // WHEN
        String result = FizzBuzz.fizzBuzz(number);
        // THEN
        assertEquals("1", result);
    }
}

Partie optionnelle : un test par règle

Vos tests se répètent : seule la valeur change. @ParameterizedTest lance le même test avec plusieurs valeurs, écrites en dur dans @ValueSource. On regroupe alors les valeurs par règle métier : un test par règle, pas un test par valeur.

import org.junit.jupiter.params.ParameterizedTest;
import org.junit.jupiter.params.provider.ValueSource;

@ParameterizedTest
@ValueSource(ints = {3, 9, 21})
void fizzBuzz_oddMultipleOf3_givesFizz(int n) {
    assertEquals("Fizz", FizzBuzz.fizzBuzz(n));
}
