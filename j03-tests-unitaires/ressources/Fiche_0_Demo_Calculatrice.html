Démo : la calculatrice

Question 0, avec la formatrice

Étape 1. Dans le pom.xml de votre projet, ajoutez la dépendance JUnit 5, puis rechargez Maven (« Load Maven Changes », en haut à droite de l'éditeur). Si la balise <dependencies> existe déjà, ajoutez seulement la <dependency>.

<dependencies>
    <dependency>
        <groupId>org.junit.jupiter</groupId>
        <artifactId>junit-jupiter</artifactId>
        <version>5.14.0</version>
        <scope>test</scope>
    </dependency>
</dependencies>

Étape 2. Copiez Calculator.java dans src/main/java.

public class Calculator {

    public static int add(int a, int b) {
        return a + b;
    }

    public static int subtract(int a, int b) {
        return a - b;
    }

    public static int multiply(int a, int b) {
        return a * b;
    }

    public static double divide(int a, int b) {
        return (double) a / b;
    }
}

Étape 3. Dans src/test/java, créez une classe de test : CalculatorTest, le nom de la classe testée suivi de Test.

Étape 4. Écrivez avec la formatrice le premier test, add_twoPositives, et lancez le avec la flèche verte dans la marge. Vert ?

Étape 5. Créez un fichier reflexion.md. À la fin de chaque exercice, vous y répondez à une question, une section par exercice : c'est le livrable à rendre en fin de journée.

Ce qu'on teste ensemble

TestCe qu'il montre
add(6, 3) vaut 9un cas nominal, et la structure Given, When, Then
subtract, multiply, divide(6, 3)un cas nominal par calcul
divide(5, 2) vaut 2.5attention aux int : entre deux int, 5 / 2 vaut 2. Pour gérer ce cas, on passe les types en double
divide(1, 3) vaut 0.3333…la précision : une tolérance sur un double
divide(1, 0) vaut Infinityla division par zéro n'existe pas : en Java, sur un double, elle donne Double.POSITIVE_INFINITY
