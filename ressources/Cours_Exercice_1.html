Exercice 1 : à retenir

  • Team ne connaît que Hero : un nouveau héros ne change pas une ligne de Team.
  • Java appelle la méthode de l'objet réel, pas celle de l'interface.
  • Une interface ne partage aucun code : elle oblige à écrire.
  • Ajouter une méthode à l'interface oblige à la coder dans toutes les classes.
  • Une classe qui implémente une interface en écrit toutes les méthodes, même pour renvoyer 0.
