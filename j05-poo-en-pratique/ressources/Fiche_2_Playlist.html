Exercice 2 : la playlist

Le contexte : une appli de musique lie chaque chanson à son artiste. L'artiste change de nom ? Ses chansons suivent, car elles connaissent l'objet, pas une copie du nom.

Ce qui est travaillé : un attribut qui est un objet, une liste d'objets, song.getArtist().getName(), deux objets qui partagent le même objet, et protéger une liste interne.

Question 0, avec la formatrice

Copiez les classes et le Main, et lancez le.

public class Artist {
    private String name;
    public Artist(String name) { this.name = name; }
    public String getName() { return name; }
}
public class Song {
    private final String title;
    private final int durationSeconds;
    private final Artist artist; // un attribut qui est un objet
    public Song(String title, int durationSeconds, Artist artist) {
        this.title = title;
        this.durationSeconds = durationSeconds;
        this.artist = artist;
    }
    public int getDurationSeconds() { return durationSeconds; }
    public Artist getArtist() { return artist; }
    public static String format(int seconds) {
        return seconds / 60 + ":" + String.format("%02d", seconds % 60);
    }
    public String getInformation() {
        return title + " - " + artist.getName() + " (" + format(durationSeconds) + ")";
    }
}
Artist queen = new Artist("Queen");
Song song = new Song("Bohemian Rhapsody", 355, queen);
System.out.println(song.getInformation());

La consigne

  1. Créez Playlist, avec un nom et une List<Song> privée.
  2. Ajoutez add(Song), size() et getTotalDuration(), la durée totale au format 13:16.
  3. Ajoutez songsBy(Artist), qui renvoie la liste des titres d'un artiste, et longest(), le titre le plus long.
  4. Dans le Main, affichez Bohemian Rhapsody (355 s) et Don't Stop Me Now (209 s) de Queen, Papaoutai (232 s) de Stromae.

reflexion.md :

  • Song a un attribut artist de type Artist, et non un String. Pour afficher le nom de l'artiste d'une chanson, qu'avez-vous écrit ? Pourquoi faut-il deux appels ?
  • Votre playlist contient trois Song, et deux d'entre elles sont de Queen. Combien d'objets Artist existent dans votre programme ? Combien d'objets Song ?

Étape 2 : l'artiste change de nom

Queen tourne désormais avec Adam Lambert. Ajoutez rename(String newName) dans Artist. Dans le Main, après avoir rempli la playlist, renommez queen en « Queen + Adam Lambert », puis affichez à nouveau la playlist.

Créez ensuite un second artiste au même nom, Artist otherQueen = new Artist("Queen + Adam Lambert");. Affichez combien de titres trouvent playlist.songsBy(queen) et playlist.songsBy(otherQueen), et comparez.

reflexion.md :

  • Vous n'avez renommé qu'un seul objet Artist. Que deviennent les deux titres de Queen dans la playlist ? Pourquoi ?
  • queen et otherQueen portent le même nom. songsBy trouve-t-il le même nombre de titres pour les deux ? Pourquoi ?

Étape 3 : protéger la playlist

Ajoutez dans Playlist une méthode getSongs(), qui retourne la liste des chansons. Dans le Main, appelez playlist.getSongs().clear();, puis affichez playlist.size().

Une playlist ne devrait se vider que si on le lui demande. Modifiez getSongs() pour que ce clear() ne puisse plus toucher à la playlist. Indice : List.copyOf.

reflexion.md :

  • Que devient la playlist après clear(), avant votre correction ? Comment l'avez-vous empêché, et pourquoi ça marche ?
